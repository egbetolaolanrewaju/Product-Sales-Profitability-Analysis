# Product Sales & Profitability Analysis Dashboard

## Project Overview

An interactive **Product Sales & Profitability Analysis Dashboard** designed to analyze sales performance, profitability, customer activity, regional performance, and sales representative revenue.

The dashboard transforms raw sales data into actionable business insights using key performance indicators (KPIs), interactive filters, and visual analytics.

## Objective

The primary objective of this project is to provide a clear overview of business performance and help stakeholders understand:

- Overall revenue and profit performance
- Cost of Goods Sold (COGS)
- Product-level profitability
- Customer trends
- Regional cost distribution
- Sales representative performance
- Product and category performance

## Dashboard Features

### 1. Product Profitability Analysis

The **Product by Profit** visualization compares profit generated by individual products.

This helps identify high-performing and lower-performing products and provides insight into product profitability.

### 2. Regional COGS Analysis

The **City by COGS** donut chart shows the distribution of Cost of Goods Sold across major cities:

- Abuja
- Port Harcourt
- Kano
- Lagos

This provides a visual comparison of the cost contribution from each location.

### 3. Customer Trend Analysis

The **Monthly Customer** line chart tracks customer activity across the available periods and helps identify changes in customer volume over time.

### 4. Sales Representative Performance

The **Sales Rep by Revenue** chart compares revenue generated by individual sales representatives.

This allows stakeholders to evaluate revenue contribution across the sales team.

### 5. Interactive Filtering

The dashboard includes interactive filters for:

- Product Category
- Region

Users can select specific categories or regions to dynamically analyze the corresponding business performance.
